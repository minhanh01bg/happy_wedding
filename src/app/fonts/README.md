# Font chữ cho Hỷ Studio

Be Vietnam Pro (400, 500, 600, 700) dùng cho nội dung và thao tác; Lora variable (400–700, normal/italic) dùng cho tiêu đề và tên cặp đôi.

Nguồn chính thức: [Be Vietnam Pro](https://github.com/google/fonts/tree/main/ofl/bevietnampro), [Lora](https://github.com/google/fonts/tree/main/ofl/lora). Tải ngày 06/10/2026 từ kho Google Fonts, chuyển TTF sang WOFF2 bằng fontTools, giữ toàn bộ bảng ký tự; không subset mất dấu tiếng Việt. Hai file OFL kèm theo giữ nguyên giấy phép và thông tin tác giả. `next/font/local` phục vụ font cùng origin, không tải từ Google khi build hoặc khi khách truy cập.
